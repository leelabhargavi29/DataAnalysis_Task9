Task 9 - Support Vector Machine (SVM)

Objective:
To classify Iris flowers and compare Linear and RBF kernels.

Tools used:
- Python
- Scikit-learn

Output:
- Linear Kernel Accuracy
- RBF Kernel Accuracy
- Confusion Matrix

Interview Questions:
1. What is a Hyperplane?
A hyperplane is the decision boundary used by SVM to separate different classes. It chooses the boundary with the maximum margin for better accuracy.
2. What is the Kernel Trick?
The Kernel Trick helps SVM classify non-linear data by mapping it to a higher-dimensional space without calculating the transformation directly. It makes classification easier.
